# VCC_2

## Project Overview:
Assignment 2 of Version Control &amp; Collaboration course.

---

## Breakdown:
This repository is intended to exemplify some of the skills required to successfully operate and collaborate on GitHub. It mainly covers repository creation (initial commit), cloning a repository on a local machine, branching off the main to work on a developer branch.

## Lessons learned:
Key takeaways:
  - Branching (working on a developer branch)
  - Pull/Merge Requests (instead of merging directly to the main branch, creating a pull request to initiate a code review, so that the code can be safely merged into the main when it's production-ready)
  - AI (assigning tasks/issues to Copilot for a more streamlined workflow)
  - Git Commands (e.g., git log --oneline; git remote -v; git branch; git checkout; etc...)
